Руководство пользователя программы «Счётчик» (папка bd)

1. Назначение программы
Программа представляет собой графический счётчик, который автоматически сохраняет каждое действие в базу данных SQLite. Программа позволяет не только считать, но и вести историю изменений.

2. Запуск программы
Откройте терминал (в VS Code или на macOS).

Перейдите в папку с проектом bd:
cd bd

Запустите скрипт:
python3 counter.py

3. Интерфейс программы
После запуска откроется окно с тёмным фоном. Оно состоит из нескольких элементов:
Дисплей (большая цифра по центру) — показывает текущее значение счётчика.
Кнопка − (красная) — уменьшает значение на 1.
Кнопка Сброс (серая) — обнуляет счётчик (ставит 0).
Кнопка + (зелёная) — увеличивает значение на 1.
Кнопка +10 (зелёная) — увеличивает значение сразу на 10.
Кнопка −10 (красная) — уменьшает значение сразу на 10.
Кнопка Сохранить (тёмно-серая) — фиксирует текущее значение в базе данных как «основное» (оно загрузится при следующем запуске).

4. Как пользоваться
Изменение значения: Нажимайте на кнопки +, −, +10, −10. Дисплей будет обновляться мгновенно, а каждое нажатие автоматически записывается в историю (таблица history).
Ограничение: Программа не позволяет уйти в минус. Если вы нажмёте − или −10 на нуле, появится предупреждающее сообщение «Нельзя уходить в минус», и значение останется равным 0.
Сброс: Кнопка Сброс мгновенно обнуляет счётчик.
Сохранение: Если вы хотите, чтобы при следующем запуске программы на экране было именно текущее число, нажмите кнопку Сохранить. Появится сообщение об успешном сохранении. (Если не нажать эту кнопку, при следующем запуске загрузится то число, которое было сохранено в прошлый раз).
Закрытие: Чтобы выйти из программы, просто закройте окно (крестик в левом верхнем углу или Cmd + Q).

5. Работа с базой данных (для проверки)
Все данные хранятся в файле counter.db (в папке bd). Посмотреть их можно через терминал:
Откройте базу:

sqlite3 counter.db

Посмотрите список таблиц:
.tables
(Вы увидите customers и history)

Посмотрите текущее сохраненное значение:
SELECT * FROM customers;

Посмотрите полную историю нажатий:
SELECT * FROM history;

Выйдите из базы:
.quit
